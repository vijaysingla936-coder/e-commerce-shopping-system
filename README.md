# E-Commerce Shopping System

Simple E-commerce shopping cart system built in Java for beginners.

## Features
- Product listing with price and stock
- Add product to cart
- View cart and total bill
- Checkout system

## Tech Stack
- Java (Core Java, OOP Concepts)
- Git & GitHub

## How to Run
1. Compile: javac Product.java Main.java
2. Run: java Main
