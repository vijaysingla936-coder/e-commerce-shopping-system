# E-Commerce Shopping System

Simple E-commerce shopping cart system built in Java for beginners.
Made for 1st semester college project.

## Features
- Product browsing and searching
- Shopping cart management
- Customer management
- Order placing and delivery
- Payment with discount

## Project Modules (6 Files)

1. Main.java - Main class to run the project
2. Product.java - Product details
3. Cart.java - Add/remove items from cart
4. Customer.java - Customer details
5. Payment.java - Payment methods
6. Order.java - Order confirm and delivery

## How to Run
Compile: javac Main.java
Run: java Main
